# COVID-19 Chest X-Ray Classification and Explainability Evaluation Framework

A research-oriented Explainable Computer Vision (XCV) framework for multi-class chest X-ray classification using DenseNet121. The project evaluates Grad-CAM and Integrated Gradients using multiple explainability dimensions including faithfulness, localization, consistency, robustness, correlation analysis, and composite reliability scoring.

---

## Objective

The objective of this project is not only to classify chest X-ray images into:

- COVID-19
- Normal
- Viral Pneumonia

but also to systematically evaluate the reliability of explanation methods generated by deep learning models.

The framework investigates whether commonly used XAI metrics agree with each other and identifies conflicts between faithfulness and clinical plausibility, leading to the proposal of a composite evaluation framework.

---

## Features

### Classification

- DenseNet121 transfer learning model
- Multi-class chest X-ray classification
- Early stopping and checkpointing
- Accuracy, Precision, Recall and F1-score evaluation
- Confusion matrix generation

### Explainability Methods

Implemented saliency methods:

- Grad-CAM
- Integrated Gradients

### Explainability Evaluation Metrics

#### Faithfulness Metrics

- Area Over Perturbation Curve (AOPC)
- Insertion AUC
- Deletion AUC

#### Localization Metrics

- Saliency Entropy
- Lung Focus Score (LFS)

#### Consistency Metrics

- Spearman Concordance
- Top-k Saliency Overlap

#### Robustness Metrics

- Noise Robustness
- Brightness Robustness
- Rotation Robustness

#### Correlation Analysis

- Pearson Correlation
- Spearman Correlation
- Metric Conflict Discovery

### Composite Evaluation

- CERS (Composite Explainability Reliability Score)
- C-CERS (Consensus-Adjusted CERS)

### Additional Analysis

- Method Ranking
- Research Gap Identification
- Metric Conflict Analysis
- Explainability Conflict Frontier Visualization
- Multi-Criteria Explainability Index (MCI)

## Key Findings

### Classification Performance

* Accuracy: 98.85%
* Precision: 98.87%
* Recall: 98.85%
* F1 Score: 98.85%

### Explainability Findings

* Grad-CAM achieved stronger localization performance.
* Integrated Gradients achieved better deletion-based faithfulness.
* Robustness analysis favored Grad-CAM.
* Correlation analysis revealed significant conflicts between explainability metrics.
* Low cross-method agreement demonstrated that different saliency methods often highlight different regions.

### Research Gap

The study shows that no individual explainability metric can fully characterize explanation quality.

Faithfulness, localization, robustness, and consistency metrics frequently produce conflicting rankings.

This motivates the use of a composite evaluation framework.

### Proposed Framework

CERS combines:

* Faithfulness
* Localization
* Robustness

into a unified reliability score.

C-CERS further adjusts scores using cross-method consensus information.
